# kitty-session-manager

Сохранение и восстановление окон и вкладок kitty через remote control. Контракт и ограничения описаны в `contract.md`.

## Ручной запуск

Нужны Linux, Python 3.11 или новее, kitty и библиотека `rich`. Способ установки проекта и его зависимостей будет определен отдельно.

Создайте каталог `$XDG_CONFIG_HOME/kitty-session-manager` или `~/.config/kitty-session-manager` и скопируйте туда `config.toml`. Настройте kitty и шаблон сокета в конфиге так, чтобы они совпадали. Например, для поставляемого конфига укажите в kitty `listen_on unix:/tmp/mykitty-{kitty_pid}` и включите доступ к remote control.

- `./savesession` сохраняет текущий экземпляр kitty.
- `./savesession --all` сохраняет найденные экземпляры с ограничением из конфига. `-n N` задает ограничение на один запуск.
- `./loadsession` открывает меню выбора снимка. `--pick N` выбирает снимок без меню, `--add` добавляет вкладки, `--replace` заменяет старые.
- `./savesession --all --background` записывает отчеты при ошибках и отправляет уведомление через `notify-send`, если команда доступна. `./savesession --errors` открывает отчеты в терминале.

Автоматический запуск не настраивается. Параметры автосохранения в конфиге зарезервированы для будущего установщика.

Проверка: `python3 -B -m unittest discover -s tests -v`.
